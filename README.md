# Correlation Guesser

Ein Lerntool zum Schätzen von Pearson-Korrelation und Spearman-Rangkorrelation anhand von Punktwolken.

## Lokal starten

Das Projekt verwendet JavaScript-ES-Module. Öffne den Projektordner in VS Code und starte `index.html` über die Erweiterung **Live Server**. Ein Doppelklick auf die HTML-Datei reicht nicht, da Browser ES-Module dabei nicht zuverlässig laden.

Die Datei `test.html` enthält einen kleinen Test-Runner für die Statistikfunktionen und den Seed-RNG und kann ebenfalls über Live Server geöffnet werden.

## GitHub Pages

Das Projekt ist als statische Website angelegt und kann über GitHub Pages veröffentlicht werden.
