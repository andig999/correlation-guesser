# Correlation-Quest

Ein Lerntool im Pixel-Art-RPG-Stil zum Schätzen von Pearson-Korrelation und Spearman-Rangkorrelation anhand von Punktwolken. Im Spiel reagieren die Figuren auf Schätzungen; Herz- und Münz-Icons zeigen Leben und Belohnungen.

## Lokal starten

Das Projekt verwendet JavaScript-ES-Module. Öffne den Projektordner in VS Code und starte `index.html` über die Erweiterung **Live Server**. Ein Doppelklick auf die HTML-Datei reicht nicht, da Browser ES-Module dabei nicht zuverlässig laden.

Die Datei `test.html` enthält Tests für Statistik, Seed-RNG, Szenarien, Spielregeln und Plot und kann ebenfalls über Live Server geöffnet werden.
